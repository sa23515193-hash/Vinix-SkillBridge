
# SkillBridge — Career Exploration Platform

A modern, responsive career exploration website designed to help learners discover technology fields, explore learning pathways, and build career-ready skills.

## 🚀 Project Overview

SkillBridge provides a clean and user-friendly interface for exploring different technology career paths, including web development, data analytics, and UI/UX design.

The project focuses on responsive layouts, accessible navigation, reusable styling, and a professional user experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern landing page and navigation menu
- Career and skill category cards
- Learning pathway sections
- Step-by-step learning guidance
- Mobile-friendly navigation
- Clean typography and consistent visual styling
- Structured HTML, CSS, and JavaScript files

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, layouts, and responsive design
- **JavaScript** — Interactive navigation and interface behavior

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.

## 📱 Responsive Design

The layout is designed to adapt to different screen sizes, providing a consistent experience across desktop, tablet, and mobile devices.
